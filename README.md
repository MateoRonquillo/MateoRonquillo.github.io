# Bitácora de Mateo Ronquillo

Sitio personal y portafolio estático, en español, compatible con GitHub Pages y Jekyll. No necesita plugins externos ni un paso de compilación personalizado.

## Publicarlo en GitHub Pages

1. Sube estos archivos a la rama `main` de un repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`.
4. Guarda. GitHub Pages compilará el sitio con Jekyll y mostrará la URL publicada.

Si usas un repositorio de proyecto, Pages aplica el subpath automáticamente mediante `relative_url`.

## Personalizar

- Edita `index.md` y `about.md` para ajustar la presentación.
- Añade publicaciones Markdown a `_posts/` usando el formato `AAAA-MM-DD-titulo.md` y el front matter que aparece en las notas de ejemplo.
- Cambia `title` y `description` en `_config.yml`.
- Ajusta colores y estilos en `assets/css/style.css`.

Las notas iniciales se redactaron a partir de proyectos y temas trabajados: EduMonitorAI, gestión de cambios, bases de datos, redes y metodologías ágiles. Revisa cualquier dato o formulación antes de publicarlo.

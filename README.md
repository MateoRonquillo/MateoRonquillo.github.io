# Portafolio de Mateo Ronquillo

Portafolio web estático en español, compatible con GitHub Pages y Jekyll. No requiere plugins externos ni un proceso de compilación personalizado.

## Publicación en GitHub Pages

1. Sube los archivos al repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/ (root)`.
4. Guarda. GitHub Pages compilará el sitio con Jekyll y mostrará la URL publicada.

Los enlaces usan `relative_url`, por lo que funcionan tanto en un dominio personalizado como bajo la ruta de un repositorio de proyecto.

## Actualización del contenido

- Edita `index.md` y `about.md` para actualizar el perfil y la presentación.
- Añade proyectos o artículos en `_posts/` con el formato `AAAA-MM-DD-titulo.md`.
- Actualiza el nombre y la descripción en `_config.yml`.
- Modifica la paleta y los estilos en `assets/css/style.css`.

El contenido inicial presenta proyectos y áreas de trabajo compartidas en este contexto. Revisa datos y descripciones antes de publicar y añade enlaces a repositorios, correo o perfiles profesionales cuando quieras hacerlos públicos.

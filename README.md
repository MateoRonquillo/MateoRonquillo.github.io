# Bitácora de Mateo Ronquillo

Portafolio personal estático en español, compatible con GitHub Pages y Jekyll. No requiere plugins ni un paso de compilación personalizado.

## Publicación en GitHub Pages

1. Sube estos archivos a la rama `main` de un repositorio.
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guarda. GitHub Pages compilará el sitio con Jekyll y mostrará la URL publicada.

El sitio utiliza `relative_url` para admitir tanto repositorios de usuario como repositorios de proyecto.

## Mantenimiento

- Edita `index.md` y `about.md` para actualizar la presentación profesional.
- Añade publicaciones en `_posts/` con el formato `AAAA-MM-DD-titulo.md` y los metadatos de las notas existentes.
- Ajusta el nombre y la descripción en `_config.yml`.
- Modifica la paleta y presentación en `assets/css/style.css`.

El contenido resume proyectos y áreas técnicas trabajados hasta la fecha. Revisa nombres, alcance y formulaciones antes de publicar como perfil profesional.
